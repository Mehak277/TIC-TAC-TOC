# TIC-TAC-TOC
🎮 Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript. This project recreates the classic 3x3 grid game where two players take turns marking Xs and Os, aiming to align three of their symbols in a row, column, or diagonal.

🚀 Features

🧠 Two-player mode (Player X vs Player O)

💡 Displays current player’s turn

🏁 Detects win, draw, and resets automatically

🎨 Responsive and visually appealing UI

⚡ Lightweight and runs directly in your browser — no setup required

🛠️ Tech Stack

HTML – Structure of the game board and layout

CSS – Styling, animations, and responsive design

JavaScript – Game logic, event handling, and interactivity

📋 How to Play

Open the game in your browser.

Player X starts the game.

Click on a box to place your mark.

The first player to align three marks horizontally, vertically, or diagonally wins!

If all boxes are filled and there’s no winner, the game ends in a draw.
